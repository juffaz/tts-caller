## Этапы реализации

```
1. [ПОДГОТОВКА]
   ├── Проверить Java версию (≥17)
   ├── Добавить зависимости в project.clj
   └── Скачать турецкую модель Piper
       └── resources/piper-models/

2. [ИССЛЕДОВАНИЕ]
   ├── Проверить NonEnglishModels в model-downloader
   │   └── Есть ли турецкая модель встроенная?
   └── Изучить структуру ModelConfig
       └── Нужно ли реализовывать кастомный Model?

3. [РЕАЛИЗАЦИЯ]
   ├── audio.clj
   │   ├── Добавить импорты Voices
   │   ├── defonce piper-chorus
   │   ├── defonce turkish-voice
   │   ├── generate-audio-bytes-piper
   │   └── Добавить case "piper" в generate-final-wav-auto
   │
   └── (опционально) piper_model.clj
       └── Кастомная реализация Model для турецкой модели

4. [ТЕСТИРОВАНИЕ]
   ├── REPL тест
   │   └── (generate-final-wav-auto "Salam" "/tmp/test.wav" :tts-engine "piper")
   │
   ├── HTTP API тест
   │   └── curl "localhost:8899/call?text=Test&phone=1001&engine=piper"
   │
   └── SIP end-to-end тест
       └── Проверить качество звука в реальном звонке

5. [ОПТИМИЗАЦИЯ]
   ├── Решить проблему потокобезопасности
   │   └── locking или пул Chorus instances
   │
   ├── Настроить параметры качества
   │   └── speed, gain, модель (medium vs high)
   │
   └── Замерить производительность
       └── Сравнить с espeak-ng и MaryTTS
```

## Критические точки

```
⚠️  РИСК 1: Нет готовой азербайджанской модели
    └─→ Решение: использовать турецкую (фонетика похожа)
    └─→ Fallback: обучить свою модель Piper

⚠️  РИСК 2: Сложность загрузки кастомной модели
    └─→ Решение: использовать model-downloader если есть турецкий
    └─→ Fallback: реализовать кастомный Model wrapper

⚠️  РИСК 3: Chorus не потокобезопасен
    └─→ Решение: добавить синхронизацию через locking
    └─→ Альтернатива: создавать новый Chorus на запрос (медленнее)

⚠️  РИСК 4: Java версия < 17
    └─→ Решение: обновить JDK
    └─→ Проверка: java -version
```
